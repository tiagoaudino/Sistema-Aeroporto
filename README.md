# Sistema-Aeroporto
# ✈️ Sistema de Controle de Voos

Projeto desenvolvido em Java para a disciplina de Programação Orientada a Objetos.

O sistema realiza o controle de voos de um aeroporto, trabalhando com três categorias:

- Voos nacionais
- Voos internacionais
- Voos de carga

## Funcionalidades

- Cadastro de voos
- Busca por código
- Listagem dos voos
- Verificação de autorização para decolagem
- Cálculo do combustível necessário
- Cálculo do custo operacional
- Identificação do voo com maior custo
- Controle de códigos duplicados

## Conceitos utilizados

O projeto aplica conceitos de Programação Orientada a Objetos, como:

- Herança
- Classe abstrata
- Interface
- Sobrescrita de métodos (`@Override`)
- Encapsulamento
- Polimorfismo
- `ArrayList`
